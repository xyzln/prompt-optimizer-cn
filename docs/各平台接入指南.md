# 各平台接入指南

把 Prompt Optimizer-CN 装进你常用的 Agent。**入口名称随版本更新可能变化，以 App 内实际为准**（欢迎 PR 更新）。

## 速查表

| 平台 | 载体 | 操作 |
|---|---|---|
| Claude Code | [SKILL.md](../SKILL.md) | 装到 `~/.claude/skills/prompt-optimizer-cn/` |
| Codex / Cursor / Aider | [AGENTS.md](../AGENTS.md) | 复制到项目根目录 |
| ChatGPT | [prompts/system-prompt.md](../prompts/system-prompt.md) | 自定义指令 / GPTs Instructions 粘贴 |
| Claude 网页版 | 同上 | Projects → 自定义指令粘贴 |
| 豆包 | 同上 | 创建智能体 → 设定粘贴 |
| 通义千问 | 同上 | 百炼应用 / 智能体提示词粘贴 |
| DeepSeek | 同上 | API system prompt / 对话首条粘贴 |
| WorkBuddy 等 | 同上 | 通用粘贴法（见下） |

## 分平台步骤

### Claude Code

```bash
mkdir -p ~/.claude/skills/prompt-optimizer-cn
curl -o ~/.claude/skills/prompt-optimizer-cn/SKILL.md \
  https://raw.githubusercontent.com/xyzln/prompt-optimizer-cn/main/SKILL.md
```

说「优化提示词：……」触发。

### Codex / Cursor / Aider（AGENTS.md 生态）

复制本仓库 `AGENTS.md` 到你的项目根目录，Agent 每次任务自动读取。

### ChatGPT

- **自定义指令**：头像 → 设置 → 个性化 → 自定义指令 → 把 `prompts/system-prompt.md` 代码块全文贴入「希望 ChatGPT 如何回复」（字段上限 1500 字符，本提示词约 800 字，放得下）
- **GPTs**：创建 GPT → Configure → Instructions 粘贴全文，效果最佳

### Claude 网页版

Projects → 新建项目 → 自定义指令（Custom Instructions）→ 粘贴 `prompts/system-prompt.md` 代码块全文。

### 豆包

发现页 → 「创建 AI 智能体」→ 「设定/人设描述」粘贴 `prompts/system-prompt.md` 代码块全文 → 发布或仅自己可用。

### 通义千问

- **百炼平台**：控制台 → 应用管理 → 新建应用 → 系统提示词粘贴
- **千问 App**：智能体 → 创建智能体 → 设定粘贴

### DeepSeek

- **API**：`messages` 首条 `{"role": "system", "content": "<system-prompt.md 代码块全文>"}`
- **网页/App**（无固定自定义指令入口）：新对话首条消息粘贴全文，末尾加一句「此后按以上规则处理我的需求」

### WorkBuddy 及其他 Agent

通用兜底法，两步：

1. 新对话首条消息粘贴 `prompts/system-prompt.md` 代码块全文
2. 末尾加「此后按以上规则处理我的需求」，然后正常发需求

> WorkBuddy 的自定义指令入口未核实（搜索时无可信公开资料），若其支持智能体/助手设定，优先贴设定里；不支持则用兜底法。确认后欢迎 PR 补充。

## 注意

- 粘贴版**每次新对话生效一次**：长对话中模型可能"忘记"指令，发现输出跑偏时把压缩稿要求复述一遍即可。
- 有字数上限的平台优先保留「流程 + 禁区 + 输出格式」三段。
